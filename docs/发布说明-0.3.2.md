# Atelier 0.3.2

- 适配 DSH 0.1.3-alpha.2（c389f96），使用原生右侧插件区域。
- Node.js 后端、持久化项目与任务；每组动作迁移素材对应独立项目。
- RunningHub API Key 加密存入 SQLite，主密钥由系统保护。
- 详情返回按钮增强，设置加入 Tab；头部展示版本及按需更新提示。
- 提供 Windows 与 macOS 本地编译、重启脚本。

需要 Node 22.19 或 >=24。安装后重启 DSH；升级前备份数据目录与系统保护密钥。旧版数据库升级后不保证能由旧代码读取。macOS 尚未原生验收，本次验证不调用付费生成接口。
