# Atelier 0.3.5

- 适配 DSH 0.1.6-alpha.1，宿主依赖由 0.1.3-alpha.2 升级到 0.1.6-alpha.1。
- Typert 契约按新协议重新生成：编解码声明由 `schema` 改为 `create` 惰性构造，旧契约在新宿主上会失效。
- 新增 `scripts/internal/regenerate-typert.mjs`，宿主生成器升级后只重生成契约，不重建前后端。
- 功能与 0.3.4 一致，本次未改动界面与业务逻辑。

需要 Node 22.19 或 >=24，DSH 0.1.6-alpha.1。更新后请重启 DSH Web。升级前建议备份 Atelier 数据目录与系统保护的主密钥。本次发布不调用付费生成接口。
