# Atelier 0.3.3

- 项目与任务模型分离，每组动作迁移素材创建独立项目。
- RunningHub 排队与运行状态分开展示，任务状态变化才写入事件，避免重复事件。
- `listEvents` 作为全局增量入口固定每两秒查询，项目和任务详情按事件刷新。
- 任务详情完善平台、节点参数、配置参数和图片、视频、音频产物展示。
- 后端改为随插件托管启动的 Node.js 服务，API Key 使用系统主密钥加密保存。
- 修复 DSH 源码依赖品牌类型冲突、旧构建产物残留和任务详情重复轮询。
- 精简构建与测试流程，移除 Go 后端及无关迁移检测。

需要 Node 22.19 或 >=24。安装或更新后重启 DSH。升级前建议备份 Atelier 数据目录与系统保护的主密钥。本次发布不调用付费生成接口。
