# 接口说明

Node / Fastify 默认监听 `127.0.0.1:8787`，API 不做请求鉴权，不需要 Authorization 或其他访问令牌。RunningHub API Key 仅用于后端调用平台接口。浏览器仍调用 DSH 同源桥接。请求大小、业务参数和会话归属校验继续保留；JSON 失败响应为 `{ "error": "说明" }`。`/health` 额外返回 `runtime: "node"`，apiVersion 保持 1。OpenAPI 是公开字段契约源，`node scripts/generate-contracts.mjs --check` 检查类型一致性。

| 方法与路径                         | 用途                                                                                           |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| GET /health                        | 连接检查，返回 version、apiVersion: 1 和 capabilities，asset-delete 表示支持删除               |
| GET /config                        | 脱敏账户配置                                                                                   |
| PUT /config                        | 保存 baseUrl；apiKey 为空保留原值；旧 concurrency 字段忽略，容量从平台动态查询                 |
| GET /workflows                     | 工作流列表                                                                                     |
| PUT /workflows/:id                 | 带 revision 保存工作流；新 ID 可创建                                                           |
| DELETE /workflows/:id              | 删除定义，保留任务快照                                                                         |
| DELETE /assets                     | 批量逻辑删除素材；请求体 `{sessionId, ids}`，1..200 项，跨会话或不存在则整体回滚；保留历史文件 |
| GET /assets?sessionId=             | 素材列表；不返回路径                                                                           |
| POST /assets                       | multipart file + sessionId 上传                                                                |
| POST /assets/import                | Host 专用：sessionId + path，本机绝对路径导入                                                  |
| GET /assets/:id/file               | 本地文件，支持 Range；download=1 为附件下载                                                    |
| GET /assets/:id/selection          | 受管素材绝对路径，供 Host 选择适配                                                             |
| POST /tasks                        | 事务幂等创建批次                                                                               |
| GET /tasks                         | sessionId、state、page、pageSize，返回 items/total/summary                                     |
| GET /tasks/:id                     | task 与 attempts                                                                               |
| POST /tasks/:id/cancel             | 记录取消意图                                                                                   |
| POST /tasks/:id/retry              | `{revision}`，人工重试失败任务                                                                 |
| POST /tasks/:id/reconcile          | `{remoteId}`，关联未知提交                                                                     |
| GET /events?after=                 | 游标增量，最多 200 条                                                                          |
| GET /events?notifications=1&after= | 待投递通知                                                                                     |
| POST /events/:seq/ack              | 持久化投递确认                                                                                 |
| POST /shutdown                     | 托管进程内部停机，不通过浏览器 Remote 暴露                                                     |

## 创建任务

```json
{
  "sessionId": "来源会话",
  "requestId": "稳定请求标识",
  "tasks": [
    {
      "title": "动作迁移",
      "workflowId": "wan-animate2",
      "imageId": "已导入图片 ID",
      "videoId": "已导入视频 ID",
      "parameters": { "width": 480, "height": 848, "frames": 81, "skip": 0 }
    }
  ]
}
```

`requestId` 重放时必须保持任务输入一致。任务最多 100 项；dimensions 64..4096 且为 8 的倍数；frames/skip 非负。省略 parameters 使用工作流默认值，传入时必须包含全部四个字段。

## 模型工具

`atelier_capabilities`、`atelier_asset_list`、`atelier_asset_import`、`atelier_task_create`、`atelier_task_list`、`atelier_task_get`、`atelier_task_cancel`、`atelier_task_retry`。每个工具接收 `payload` JSON 字符串并返回业务 JSON 字符串；sessionId 永远取执行上下文，不信任模型传入。

## 工作流节点

| 字段   | nodeId | fieldName |
| ------ | ------ | --------- |
| width  | 709    | value     |
| height | 712    | value     |
| frames | 746    | value     |
| skip   | 747    | value     |
| image  | 189    | image     |
| video  | 604    | video     |

平台 workflowId 为 `2096817694862565378`。图片和视频 fieldValue 使用上传响应的 fileName，不拼接为下载外链。平台查询结果不带节点 ID 时，按 outputType 筛选全部视频。输出音轨使用平台文件原样保留。

# 工作台全局视图补充

页面查询 `/tasks`、`/assets` 及任务详情不再传 `sessionId`，表示当前 profile 全量数据。模型工具仍传入执行会话进行任务权限校验。`DELETE /assets` 的 `sessionId` 改为可选：省略时为本机工作台全局删除，传入时仍限制素材归属；批量事务和历史文件保留规则不变。素材来源不再限制新任务复用，任务自身仍记录创建会话。
