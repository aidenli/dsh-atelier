# 操作式接口（apiVersion 2）

读取使用 GET，写入使用 POST。接口路径直接标识操作，不使用资源 ID 路径、PUT 或 DELETE。ID、分页和会话范围通过 query 传入，写入内容使用 JSON body。

浏览器通过 DSH 同源 `/api/atelier.操作名` 访问，例如 `GET /api/atelier.getTask?id=task-...`。Host 根据插件配置连接 Node 后端的 `/操作名`，不通过统一 Remote 请求分发。

| GET 操作 | 含义 |
| --- | --- |
| getHealth | 后端健康及 API 能力 |
| getConfig | RunningHub 配置状态，不返回密钥 |
| listWorkflows | 工作流列表 |
| listProjects / getProject | 项目列表 / 详情，详情 query 传 id |
| listTasks / getTask | 任务列表 / 详情，详情 query 传 id |
| listAssets / getAssetSelection | 素材列表 / 选择信息 |
| listEvents | 事件增量，query 传 after、notifications |
| getAssetFile | 素材文件，query 传 id、download；支持 Range 和只读 HEAD |

| POST 操作 | 参数 |
| --- | --- |
| saveConfig | body: baseUrl、apiKey |
| saveWorkflow | query: id；body: 工作流配置 |
| deleteWorkflow | query: id |
| deleteAssets | body: ids、可选 sessionId |
| uploadAsset | multipart: file、sessionId |
| importAsset | Host 专用；body: path、sessionId、可选 sourceId/name |
| createTasks | body: sessionId、requestId、tasks |
| cancelTask | query: id、可选 sessionId |
| retryTask | query: id、可选 sessionId；body: revision |
| reconcileTask | query: id；body: remoteId |
| ackEvent | query: seq |

Host 另提供 GET getConnection/getVersion、POST saveConnection，分别管理后端连接和插件版本，不转发给 Node。浏览器不开放 importAsset。读取接口不会触发任务生成；文件 HEAD 为 HTTP 媒体协议支持，不是写操作。

旧 REST 路径已移除，前端、Host、Node 后端必须一起构建并重启 DSH，刷新页面后生效。第三方 RunningHub 的接口路径与方法由平台规定，本次不改动。
